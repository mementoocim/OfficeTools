# UI & Iconography Guidelines

## Rule: Avoid Unnecessary Icons in the UI Design

When designing, refactoring, or adding UI elements, adhere strictly to the following principles:

1. **No Decorative or Superfluous Icons**:
   - Do NOT add icons to every button, label, tag, or table header.
   - Text alone is cleaner, faster to read, and more professional when the label is already self-descriptive.

2. **Only Use Purpose-Driven Icons**:
   - Icons should only be used when they serve a clear utilitarian or navigational function (e.g., search magnifying glass, close `X`, collapse arrow, status spinner, or universal actions where space is tight).
   - If an element already has a clear textual label, avoid prepending or appending redundant icons unless explicitly requested.

3. **Keep Interface Clean, Minimal, and Balanced**:
   - Prioritize clean typography, intentional whitespace, subtle borders, and balanced layout over visual clutter.
   - Ensure modals, alerts, and dialogs are centered properly on screen and avoid busy visual decorations.
