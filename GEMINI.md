# Workspace Guidelines & Rules

## UI Design & Iconography Rules

- **Do Not Add Unnecessary Icons**: Avoid cluttering buttons, labels, headers, and UI elements with decorative or superfluous icons.
- **Purpose-Driven Iconography Only**: Only use icons when they serve a critical utilitarian or navigational purpose (e.g. search input, close `X`, collapse toggle, spinner). Never add icons just for decoration when clear text labels exist.
- **Clean & Minimal Design**: Maintain clean typography, generous whitespace, and balanced, centered modal dialogs.
- **Quiet, Utility-First Product Design**: The interface should feel like a carefully made desktop productivity tool, not an enterprise dashboard or a generic AI-generated SaaS template.
- **No Decorative Accent Rails**: Do not add colored left/right/top lines, inset stripes, or similar visual indicators to cards, navigation items, tabs, or buttons. Selected states should rely on a restrained background, text weight, and icon color.
- **No Decorative Dividers**: Use lines only when they clarify a real structural boundary, such as a table header, form grouping, or separate navigation region. Prefer whitespace and alignment over divider-heavy layouts.
- **Avoid Template Clichés**: Do not add gradients, glass effects, excessive pills/badges, floating icon tiles, or many rounded cards merely to make a screen look designed.
- **No Icon Tiles in Empty States**: Standalone icons in upload, empty, and success states should remain unframed. Do not place them in colored squares, circles, or soft-background containers unless the container itself is an interactive control.
- **Deliberate Surface Hierarchy**: Use a small number of surfaces: page canvas, work surface, and overlay. Borders and shadows should be subtle and functional; do not stack cards inside cards without a workflow reason.
- **Control Hierarchy**: Each area should have one clearly primary action. Use secondary and quiet actions sparingly; controls should be compact, aligned, and consistently sized.
- **Text Buttons Are Text-Only**: Do not pair an icon with a text-labeled action button. Keep icons for icon-only utility controls and persistent navigation, where a text label is unavailable or intentionally hidden.
- **Typography Before Decoration**: Establish hierarchy through type scale, weight, spacing, and concise labels before adding visual ornament.
